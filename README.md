# V.E.L.O. Landing

오컬트 아이돌 프로듀싱 리듬게임 **V.E.L.O.** 출시 전 브랜드 랜딩페이지.

> 잘못된 선택을 하면, 이야기는 처음으로 되돌아간다.

## 바로 보기
- 로컬: `index.html` 더블클릭 (서버 불필요)
- 또는: `python3 -m http.server 8000` → http://localhost:8000

## 구성
헤더 · 히어로(5인 키비주얼) · 공지+선택지투표 · 프롤로그 웹소설 · 멤버소개 · 프로듀서 클럽 · 팬존 자유게시판 · 게임 미리보기 · 개발 소식 · 푸터

정적 사이트 (HTML/CSS/JS) · Pretendard / Cormorant · 흰·검·보라 3색.

## 팬존 자유게시판
- `fan.html`에서 별도 게시판 화면을 제공합니다.
- 목록에서는 제목/작성자/날짜만 보이고, 글을 눌러야 상세 내용이 보입니다.
- 글 작성 시 이미지 1장을 첨부할 수 있습니다.
- 임시 구현은 브라우저 `localStorage`에 저장되며, 같은 브라우저에서 작성한 글만 수정/삭제할 수 있습니다.

## 프롤로그 웹소설
- `story.html`에서 0화부터 7화까지 볼 수 있습니다.
- 0~5화는 바로 열람 가능하고, 6~7화는 팬존에 `감상글`을 하나씩 남겨 순차 해금됩니다.
- 현재 해금 상태는 브라우저 `localStorage` 기준이며, 실제 개별 유저별 해금을 운영하려면 백엔드/DB/로그인이 필요합니다.

## Vercel 배포
현재 구조는 정적 사이트라 Vercel 배포가 가능합니다. 다만 여러 사용자가 함께 쓰는 실제 커뮤니티로 운영하려면 `localStorage` 대신 Supabase/Firebase/서버 DB 같은 저장소와 로그인 기능을 연결해야 합니다.

## 외부 링크 연결
`script.js` 상단의 `LAUNCH_LINKS`에 링크를 넣으면 버튼들이 자동 연결됩니다.
- `producerClub`: 텀블벅 후원 페이지
- `mvpTest`: MVP 테스트 신청 구글폼
