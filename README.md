# V.E.L.O. Landing

오컬트 아이돌 프로듀싱 리듬게임 **V.E.L.O.** 출시 전 브랜드 랜딩페이지.

> 잘못된 선택을 하면, 이야기는 처음으로 되돌아간다.

## 바로 보기
- 로컬: `index.html` 더블클릭 (서버 불필요)
- 또는: `python3 -m http.server 8000` → http://localhost:8000

정적 사이트 (HTML/CSS/JS) · Pretendard / Cormorant · 흰·검·보라 3색.
